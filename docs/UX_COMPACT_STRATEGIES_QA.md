# UX-приёмка «Евразии 2050»: компактная навигация и стратегия сравнения

**Дата:** 17 октября 2026 года  
**Основание:** предоставленный пользователем шестистраничный PDF-снимок интерфейса, сверенный с исходниками `main` от 16.10.2026.  
**Граница изменений:** интерфейс и пояснения. Правила экономики V4.7, исходные данные, кризисные сценарии, веса MAPPO, игровые сохранения и типы действий не менялись.

## 1. Выявленные проблемы

1. **Подписи графика «01 / Сравнение» не отражали выбранные стратегии** (PDF, страницы 3–4). `assets/app.js` строил график по архивным траекториям, но `selectSetup()` добавлял в оба селектора и адаптивные режимы, у которых нет готовых архивных временных рядов. При таком выборе `M.series()` выбрасывал ошибку; прежние линии и подписи оставались видимыми. Легенда становилась недостоверной. Исправлено поддержкой всех шести режимов: четыре берутся из неизменяемого архива, две адаптивные траектории пересчитываются исходным замороженным актором V4.7. Переключение селекторов синхронизирует выбранную пару, легенду, реальные линии и определения под графиком.
2. **Названия стратегий были многословными и похожими** (страницы 1, 3–4). Сформирован единый словарь из шести уникальных названий по 1–2 слова, точные описания и три группы в игровом селекторе.
3. **Первый экран и информационные карточки занимали неоправданно много высоты** (страницы 1–2). Уменьшены отступы, размеры элементов и повторы текста. Первый экран ограничен в высоте, параметры и действия доступны ближе к верху страницы.
4. **Большое число параллельных полей и повторяющих пояснений в исследовательском разделе** (страницы 3–5). Четыре основных поля выбора, ползунок года и результаты оставлены на первом уровне. Дополнительные «Дикие карты», длинные пояснения и методика скрыты за осмысленным раскрывающимся блоком.
5. **Неравномерная высота колонок и визуальная пустота в исследовательских панелях** (страницы 4–5). График вынесен на всю ширину; ниже — карта торговли, решения государств и сценарная аналитика в адаптивной сетке без принудительного выравнивания по высоте.
6. **Недостаточная мобильная навигация.** Добавлена компактная панель из четырёх ссылок и подсветка текущего раздела. При ширине 320 px доступны и функции именованного сохранения, ранее скрывавшиеся стилями мобильной версии.

## 2. Шесть названий и точное значение

| Идентификатор (не меняется) | В интерфейсе | Реальное поведение |
|---|---|---|
| `ADAPTIVE_MAPPO_GREEDY` | Адаптивный ИИ | Пересчитывает вероятности на каждом состоянии; выбирает максимальную |
| `ADAPTIVE_MAPPO` | Адаптивная выборка | Пересчитывает вероятности и использует случайную выборку из них |
| `BARGAIN` | Переговоры | Условные правила переговоров по текущему состоянию |
| `NEUTRAL` | Нейтралитет | Среднее решение по каждому направлению |
| `MAPPO_GREEDY` | Архивный ИИ | Ранее сохранённые детерминированные действия MAPPO |
| `MAPPO` | Архивная выборка | Ранее сохранённые вероятностные действия MAPPO |

Одинаковые имена используются в игровом селекторе, легендах, описаниях, результатах стран и архивной научной части. Полные описания содержатся в `EurasiaModel.policyDetails`; заголовки — в `policyNames`. В разделе сравнения две адаптивные стратегии обозначены как вычисляемые в браузере. Адаптер `EurasiaModel.getRun` получает 26-летние ряды из исходного замороженного актора и `EurasiaEngine.run`, кэширует их отдельно и сохраняет прежние архивные записи без правки. Поле `projects` сопоставлено с `new_projects` согласно двум эквивалентным подсчётам в оригинальном `EurasiaEnv`.

## 3. График «01 / Сравнение»

- Доступны шесть стратегий: четыре архивные V4.7 и две заново вычисляемые адаптивные;
- выбранная пара отображается **над графиком**, сами две линии и легенда изменяются при переключении;
- при попытке выбрать одинаковые варианты второй селектор автоматически переключается на доступную другую стратегию;
- **под графиком** раскрыто методологически корректное объяснение каждой выбранной стратегии;
- для торговли шкала и подписи используют млрд долларов; изменение среднего роста ВВП показывается в процентных пунктах;
- для каждой линии отображается происхождение (сохранённая траектория или браузерный нейросетевой расчёт); результаты не выдаются за прогноз реальной политики.

Для графика результатов отдельной игровой партии добавлен компактный раскрывающийся словарь только показанных линий и действий игрока.

## 4. Уплотнение, навигация и игровая механика

- Первый экран превращён из высокого баннера с четырьмя последовательными карточками в короткий вводный экран, где действия представлены компактно;
- игровой блок, ввод решений, карточки исходов, статистические показатели и исследовательская страница получили единый плотный ритм интервалов;
- справочник остаётся доступным по запросу; подсказки уровня «как устроена нейросеть» открываются без перегрузки страницы;
- на мобильных устройствах доступна отдельная панель «Ход — Итоги — Анализ — Справка» и ранее скрытое меню файлов партии;
- поведение кнопок «Следующий год», выбора управляемых стран, сохранения/импорта, условий «Дикой карты», адаптивной MAPPO и вычислительных сравнений сохранено.
