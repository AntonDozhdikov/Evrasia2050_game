# Новая игровая партия и редактирование текстов

## 1. Подготовка партии

Раздел **«Своя партия»** позволяет выбрать один из двадцати исследовательских сценариев либо одну из десяти «Диких карт», указать стратегию для стран, решения которых игрок не задает, и выбрать от одного до восьми управляемых государств.

Каждый игровой год с 2025-го по 2050-й включает шесть направлений решений для выбранных стран. В каждом направлении допустимы уровни 0, 1 и 2. Кнопка «Сохранить год» записывает выбранные действия. Кнопка «Следующий год» записывает текущий год и открывает следующий. При необходимости можно вернуться к любому году и изменить решения.

Результат хранится в браузере на том же устройстве. Через «Управление партиями» можно сохранить до 20 самостоятельных партий под разными именами, открыть одну из них или удалить ненужную. Текущая рабочая партия автоматически сохраняется в одном локальном профиле; при открытии другой именованной партии текущая заменяется после подтверждения. Кнопка «Скачать партию» создаёт отдельный файл с решениями, который можно загрузить на другом устройстве. При отказе браузера в локальном хранении рекомендуется скачивать файл после значимых изменений.

**Просмотр одного года:** кнопка «Показать последствия выбранного года» использует сохранённые решения игрока и стратегию автоматического продолжения. Она показывает кризисы, рост ВВП, торговлю, капитал и оценки всех восьми государств для выбранного года.

**Расчёт партии:** после сохранения решений нажмите «Рассчитать итоги». Браузер вычислит показатели за 2025–2050 годы и сравнит их с контрольными стратегиями по 21 показателю. Доступны динамика выбранной страны, её рост ВВП, модельная оценка, капитал, торговля, таблица за 26 лет и выгрузка подробных расчётов. В интерфейсе прямо указано, сколько лет определено пользователем, а сколько — стратегией. В годы, для которых игрок не сохранил действий, страны следуют выбранной исходной стратегии. Архивные результаты V4.7 можно отдельно посмотреть ниже.

**Адаптивная MAPPO (этап 3):** два дополнительных режима используют оригинальную обученную нейросеть из контрольного комплекта V4.7. В каждом году актор получает текущее состояние стран (8 × 80 признаков), пересчитывает вероятности 6 направлений действий и выбирает по ним решение. Детерминированная и вероятностная разновидности различаются способом выбора действия. Они работают как для исходных сценариев, так и для «Диких карт». Экспорт политики и испытания зафиксированы в [протоколе этапа 3](STAGE3_ADAPTIVE_REPORT.md).

**Честность сравнения:** для исходных двадцати сценариев доступны четыре архивные и контрольные стратегии. В двух **архивных** обученных режимах используется сохранённая последовательность решений MAPPO; адаптивные режимы, напротив, пересчитывают действия в каждом состоянии. Некоторые нецелевые исторические признаки браузерного наблюдения остаются зафиксированными на уровне 2024 года; полная идентичность исходной Python-среде пока не подтверждена. Для десяти «Диких карт» доступны переговорная и нейтральная стратегии, а также два адаптивных режима MAPPO; архивные траектории относятся только к исходным сценариям. Во всех расчётах применяются единые исходные условия и последовательность кризисов. «Дикие карты» сохраняют отдельное начальное число жеребьёвки кризисов и номер экономического расчёта; оба параметра экспортируются и показываются игроку. При отсутствии сохранённого номера жеребьёвки в устаревшем файле восстановление отклоняется, чтобы исключить незаметную замену событий.

Браузерный движок воспроизводит бюджетный учет, соглашения, проекты с задержкой отдачи и воздействие кризисов V4.7. Он использует собственную воспроизводимую последовательность случайных чисел, поэтому отдельные траектории отличаются от исходного Python при равных начальных числах. При отключенном шуме численные ориентиры Python проходят автоматическую проверку. Для окончательной научной приемки необходима расширенная пошаговая проверка всех типов действий и событий.

## 2. Редактор текстов

Раздел **«Редактор текстов»** содержит пять групп:

1. Названия и оба описания двадцати исходных сценариев.
2. Названия и пояснения всех ста кризисных событий.
3. Краткие и подробные описания четырех стратегий.
4. Названия, пояснения и три уровня шести направлений решений.
5. Основные пояснения главной страницы.

**Как редактировать:** выберите группу, затем запись, измените текст и нажмите «Сохранить текст». Обновленное описание появится на странице. Данные вычислительного эксперимента при этом не изменяются.

**Где сохраняются правки:** на устройстве редактора в локальном хранилище браузера. Другие посетители пока увидят исходную редакцию опубликованного сайта.

**Как перенести правки:** нажмите «Скачать исправления». На другом устройстве откройте редактор, нажмите «Загрузить исправления» и выберите полученный файл `evrazia2050_teksty.json`. Редактор проверяет состав полей и отклоняет недопустимые данные.

**Как опубликовать правки для всех посетителей:** передайте сохраненный файл сопровождающему проекта для включения в GitHub. Изменения сайта потребуют отдельного подтвержденного коммита. Сам браузерный редактор не отправляет данные в GitHub.

Кнопка «Вернуть выбранный текст» удаляет локальные правки конкретного описания. «Вернуть все тексты» восстанавливает опубликованную редакцию после подтверждения пользователя.

## 3. Сохранность исследовательских материалов

Редактор и подготовка партии работают отдельно от `assets/data.js` и каталога `research/results/`. Они не обучают модели, не меняют сохраненные политические стратегии и не заменяют архивную экономику условными величинами.

## 4. Технические проверки

```bash
node tests/verify_data.cjs
node tests/verify_scenarios.cjs
node tests/verify_party.cjs
node tests/verify_interface.cjs
node tests/verify_engine.cjs
node --check assets/party_core.js
node --check assets/party_ui.js
node --check assets/text_editor.js
```

В репозитории работает автоматическая проверка численного движка, включающая 240 сочетаний условий и сравнение контрольных траекторий с Python V4.7. Это техническая проверка переноса. При трактовке итогов следует учитывать модельный характер коэффициентов и ограниченную адаптивность двух режимов обученной стратегии.
