# Евразия 2050 — подготовка репозитория

Репозиторий создан для браузерной игры «Евразия 2050» на базе зафиксированного исследования V4.7.

Для первичной загрузки распакуйте `EURASIA_2050_STAGE3_GITHUB_READY.zip` на компьютере и выберите **Add file → Upload files** в корне репозитория. Перетащите содержимое распакованной папки, включая `index.html`, `assets/`, `.github/`, `research/`, `tests/` и `docs/`, затем нажмите **Commit changes**. Не загружайте сам ZIP как единственный файл.

Файл `UPLOAD_START_HERE.md` можно оставить; он не мешает запуску веб-приложения. После публикации откройте **Settings → Pages** и включите GitHub Actions.
