# Евразия 2050 — браузерная версия результатов V4.7

![Status](https://img.shields.io/badge/Stage_3-browser_replay-blue) ![Research](https://img.shields.io/badge/Research-V4.7-orange)

**Первая версия** — интерактивный браузерный просмотр результатов завершенной вычислительной стадии «Евразия 2050». Восемь государств, 20 сценариев, четыре политики, три начальных числа, годы 2025–2050. Используются **именно архивные результаты V4.7**, без переобучения или изменения правил экспериментальной экономики.

## Быстрый запуск

- [Открыть сайт на GitHub Pages](https://antondozhdikov.github.io/Evrasia2050_game/) (после активации Pages в настройках репозитория).
- Или открыть `index.html` из распакованного ZIP в актуальном Chrome или Яндекс Браузере. Все игровые данные загружены локально; Интернет для просмотра не нужен.
- Для разработки: `python -m http.server 8000`, затем перейти на `http://localhost:8000/`.

## Что уже работает

* Выбор сценария, режима политики, начального числа, года и сравниваемой стратегии.
* Графики, сводные показатели, граф межгосударственных связей, действия восьми агентов.
* Показатели исторического базового состояния с масками наблюдаемости.
* Выгрузка текущего состояния в JSON и траектории в CSV.
* Адаптивная верстка и работа без серверной части.

**Важно:** текущий выпуск — воспроизведение завершенного эксперимента, а не независимый движок произвольных решений игрока. Пользовательские решения будут доступны только после проверенного переноса численной экономики V4.7 из Python в браузер. Синтетические кризисы и эффекты сценариев не являются фактическими прогнозами.

## Происхождение данных и сохранность

| Артефакт | Назначение |
|---|---|
| `research/frozen/EURASIA_STAGE3_HANDOFF_V47.zip` | Неизменяемая научная передача с весами, двумя LoRA, результатами и исходниками |
| `assets/data.js` | Подготовленные для браузера архивные ряды, без использования CSV-парсера во время игры |
| `research/results/` | CSV траектории, действия, справочники, приемка, манифесты и SHA256 |
| `research/v47_source/` | Исходные Python-модули V4.7 для последующего контролируемого переноса |
| `tools/build_data.py` | Повторяемая генерация `assets/data.js` из научного ZIP |
| `tests/` | Тесты целостности данных и поведения браузерной версии |

**Не загружать** в браузер исходные Python-веса PyTorch и адаптеры Qwen; HTML воспроизводит готовые расчеты. Сетевая генерация текстов будет отдельным необязательным компонентом и не будет менять экономические результаты.

## Проверка

```bash
node tests/verify_data.cjs
python tests/verify_archive.py
node --check assets/app.js
node --check assets/model.js
```

Отдельный E2E-тест в Chromium (не входит в стандартную CI-проверку): `pip install playwright && python -m playwright install chromium && python tests/browser_smoke.py`.

Проверки подтверждают состав 240 траекторий, 6 240 годовых состояний, 49 920 действий, отсутствие пропусков годов, диапазоны уровней действий 0–2 и связь с исходным архивом. После изменения модели выполняйте дополнительные попарные проверки с Python.

## Публикация

1. Загрузить корневые файлы в ветку `main` репозитория `AntonDozhdikov/Evrasia2050_game`.
2. В **Settings → Pages** указать **Source: GitHub Actions**.
3. Workflow `.github/workflows/pages.yml` выполнит проверки и публикацию.
4. После успешного деплоя использовать адрес `https://antondozhdikov.github.io/Evrasia2050_game/`.
