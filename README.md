# Евразия 2050 — исследуйте решения восьми государств

![Status](https://img.shields.io/badge/Stage_3-browser_replay-blue) ![Research](https://img.shields.io/badge/Research-V4.7-orange)

**«Евразия 2050»** позволяет сравнить, как восемь государств действуют в разных экономических и политических условиях. Выберите сценарий, стратегию и год: графики покажут динамику торговли и экономического роста, число совместных проектов и решения каждой страны.

Пока это интерактивный просмотр 20 сценариев за 2025–2050 годы. Страны представлены четырьмя вариантами поведения; для каждого сохранены три независимых расчета. Свободное управление решениями станет доступно после переноса численного движка. Все показатели будущего взяты из зафиксированного эксперимента V4.7 и не пересчитываются браузером.

## Как пользоваться

- [Открыть игру в браузере](https://antondozhdikov.github.io/Evrasia2050_game/). Выберите сценарий и стратегию, затем перемещайтесь по годам. Выбор страны открывает ее решения. Сравнение стратегий показывает разные исходы при одинаковых условиях.
- Или открыть `index.html` из распакованного ZIP в актуальном Chrome или Яндекс Браузере. Все игровые данные загружены локально; Интернет для просмотра не нужен.
- Для разработки: `python -m http.server 8000`, затем перейти на `http://localhost:8000/`.

## Какие стратегии доступны

| Стратегия на сайте | Как принимаются решения |
|---|---|
| ИИ: наиболее вероятное решение | Обученная политика выбирает действие с наибольшей вероятностью для каждой страны. |
| ИИ: решения с вариативностью | Действия выбираются из распределения обученной политики; разные запуски могут различаться. |
| Переговоры по правилам | Контрольная переговорная стратегия с заранее заданными правилами. |
| Без новых инициатив | Контрольная нейтральная стратегия. |

Победителя заранее нет. Сравнивайте рост, договоренности, число проектов, затраты и отдачу — эти показатели отражают разные стороны модели.

## Что можно исследовать

* Выбор сценария, режима политики, начального числа, года и сравниваемой стратегии.
* Графики роста, проектов, торговли и условных индексов; сравнение двух стратегий.
* Исторические торговые направления 2024 года: 28 наблюдаемых потоков из 56 возможных, в том числе с пропусками. По выбранной стране показываются экспортные направления и суммы. Отсутствие наблюдения не означает отсутствия торговли.
* Шесть решений каждого государства за выбранный год, расшифрованных по исходным правилам модели.
* Показатели исторического базового состояния с масками наблюдаемости.
* Выгрузка текущего состояния в JSON и траектории в CSV.
* Адаптивная верстка и работа без серверной части.

**Граница интерпретации:** события будущего, макроэкономические эффекты и решения восьми стран в сценариях рассчитаны моделью. Это не наблюдаемое поведение правительств и не прогноз фактической экономики. Данные торговли за 2024 год показаны отдельно и только для подтвержденных наблюдений.

## Происхождение данных и сохранность

| Артефакт | Назначение |
|---|---|
| `research/frozen/EURASIA_STAGE3_HANDOFF_V47.zip` | Неизменяемая научная передача с весами, двумя LoRA, результатами и исходниками |
| `assets/data.js` | Подготовленные для браузера архивные ряды, без использования CSV-парсера во время игры |
| `research/results/` | CSV траектории, действия, справочники, приемка, манифесты и SHA256 |
| `research/v47_source/` | Исходные Python-модули V4.7 для последующего контролируемого переноса |
| `tools/build_data.py` | Повторяемая генерация `assets/data.js` из научного ZIP |
| `tests/` | Тесты целостности данных и поведения браузерной версии |

**Не загружать** в браузер исходные Python-веса PyTorch и адаптеры Qwen; HTML воспроизводит готовые расчеты. Сетевая генерация текстов будет отдельным необязательным компонентом и не будет менять экономические результаты.

## Проверка

```bash
node tests/verify_data.cjs
python tests/verify_archive.py
node --check assets/app.js
node --check assets/model.js
```

Отдельный E2E-тест в Chromium (не входит в стандартную CI-проверку): `pip install playwright && python -m playwright install chromium && python tests/browser_smoke.py`.

Проверки подтверждают состав 240 траекторий, 6 240 годовых состояний, 49 920 действий, отсутствие пропусков годов, диапазоны уровней действий 0–2 и связь с исходным архивом. После изменения модели выполняйте дополнительные попарные проверки с Python.

## Публикация

1. Загрузить корневые файлы в ветку `main` репозитория `AntonDozhdikov/Evrasia2050_game`.
2. В **Settings → Pages** указать **Source: Deploy from a branch**, ветка `main`, каталог `/(root)`.
3. GitHub Pages опубликует `index.html` и папку `assets` автоматически. Для проверки научных данных используйте команды из раздела «Проверка».
4. После успешного деплоя использовать адрес `https://antondozhdikov.github.io/Evrasia2050_game/`.

## Научные ограничения

Прогнозный блок V4.7 в окончательном отборе выбрал инерцию для 8 из 8 показателей. Детерминированная MAPPO в независимых испытаниях не инициирует проекты. Это отрицательные или ограниченные результаты эксперимента — они намеренно не исправляются в визуализации и не скрываются.
